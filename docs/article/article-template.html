在 Windows 上,Notepad++ 是无数人的「随手记 + 轻编辑」神器;到了 macOS,它缺席了。

自带「文本编辑」功能太弱,VS Code 又太重——记个灵感、改个配置、看个日志,都嫌折腾。于是我写了 NotepadMac:一个 macOS 原生文本编辑器,纯 Swift + AppKit,零第三方依赖,安装包仅约 1MB。

它最想做好的一件事,是随手记:点开就写,内容永不丢。在这个基础上,Notepad++ 的经典能力也基本一个不少。

主窗口:菜单栏完整收录,Markdown 高亮 + 查找高亮 + 多标签,底部状态栏实时显示 行:列 / 选区 / 编码 / 换行符 / 语言

核心承诺:打开即写,永不丢失

随手记的内容最怕丢。NotepadMac 用三重自动备份兜底:

⏱️ 停手 0.8 秒自动快照 —— 编辑停顿 0.8 秒即写入应用内备份

🔁 5 秒周期兜底 —— 不停手也有备份接力;切换标签、失焦时同步落盘

💾 退出前全部落盘 —— 正常退出把所有内容写盘

崩溃、强退、误关都不丢——重启后恢复所有标签,连未保存的正文也一并回来(顺序、光标、滚动位置、编码、换行符、语言全部还原)。

还有「历史文档」双保险:关闭过的文档自动留底(含未保存内容),默认展示最近 10 条、上限 50 条,Cmd+Shift+T 一键重开上次关闭的文档。

关闭标签 / 退出应用,只要有未保存修改必然弹窗:保存 / 不保存 / 取消

为什么选它

痛点 NotepadMac 的答案
macOS 自带文本编辑功能太弱 多标签、行号、查找替换(正则)、11 种语言语法高亮、编码/换行符处理,一个不少
编辑器写一半崩溃/误关就丢 三重自动备份(0.8s 去抖 + 5s 兜底 + 退出落盘),未保存内容跨重启恢复,关闭/退出必弹保存确认
Notepad++ 在 macOS 没有 交互全面对标:Ctrl+Tab 切换、Cmd+1..9 直达、右键关闭、状态栏、行号、GBK 编码识别
VS Code 太重、启动慢 原生 AppKit,秒开秒写,安装包仅约 1MB

核心能力

💾 自动备份:编辑 0.8 秒后自动写入应用内快照,另有 5 秒周期兜底;崩溃也不丢内容

📝 显式保存:Cmd+S 写回原文件;未命名草稿弹出存放位置选择;标签 ● 标记 = 有未保存修改

⚠️ 保存确认:关闭标签 / 退出应用,只要有未保存修改必然弹窗:保存 / 不保存 / 取消

♻️ 会话恢复:标签顺序、激活位置、光标、滚动、编码、换行符、语言全部还原,未保存正文一并恢复

🕘 历史文档:误关自动留底(含未保存内容),Cmd+Shift+T 一键重开

🗒️ 草稿本模式:Cmd+N 新建草稿直接写,无需保存对话框

📂 打开任意文本文件:Cmd+O、拖拽到窗口、Finder「打开方式」、双击文件关联(50 余种扩展名)

Notepad++ 对标功能

查找替换:全部匹配高亮、正则支持 $n 反向引用

🗂️ 多标签:折行展示、拖拽排序、Ctrl+Tab 循环切换、Cmd+1..9 直达、中键关闭、右键菜单(关闭其他/全部)

📏 行号栏:正确处理软换行,当前行高亮

📊 状态栏:行:列、选区字符数、总字符数、行数、编码、换行符类型、当前语言

🔍 查找/替换:全部匹配高亮、忽略大小写、正则($n 反向引用)、替换/全部替换

↩️ 编码:自动检测 UTF-8 / UTF-8 BOM / UTF-16 LE·BE / GB18030 / Latin-1,菜单转换保存

⏎ 换行符:检测并保持 LF / CRLF / CR,菜单一键转换(跨平台文本不乱行)

🎨 语法高亮:Markdown / JSON / Python / JavaScript·TS / Swift / C·C++ / HTML / XML / Shell / YAML / Java,按扩展名自动识别;超大文件自动降级

⏱️ 插入时间戳(Cmd+;)、大小写转换、字体缩放(Cmd +/-/0)、字体面板(Cmd+T)

🌙 自动换行开关、窗口置顶、深色模式跟随系统

编码菜单:GB18030 / UTF-16 / Latin-1 一键互转

代码模式 · 深浅色跟随系统

浅色 · Swift 高亮 + 行号 深色 · 跟随系统外观

状态栏:行:列 · 已选字符数 · 总字符 · 行数 · 编码 · 换行符 · 语言

快捷键

⌘N 新建标签  ·  ⌘O 打开文件  ·  ⌘S 立即保存(自动保存常开)  ·  ⇧⌘S 另存为

⌘W 关闭标签  ·  ⌘F / ⌥⌘F 查找 / 替换  ·  ⌘G / ⇧⌘G 查找下一个 / 上一个

⌘L 跳转到行  ·  ⌘; 插入时间戳  ·  ⌘T 字体面板  ·  ⇧⌘T 重开上次关闭的文档

⌃Tab / ⌃⇧Tab 下一个 / 上一个标签  ·  ⌘1..9 直达标签  ·  ⌘= / ⌘- / ⌘0 放大 / 缩小 / 实际大小

怎么装?

开源免费。无需完整版 Xcode,装好 Command Line Tools 即可(xcode-select --install):

git clone https://gitee.com/kevin-anycode/notepadmac.git cd notepadmac bash build.sh # 构建到 build/NotepadMac.app open build/NotepadMac.app # 直接运行 bash build.sh --install # 或安装到 /Applications

开源地址:文末「阅读原文」跳转 Gitee 仓库(GitHub 同步:kevin-anycode/notepadmac)。

数据在哪?

所有数据都在 ~/Library/Application Support/NotepadMac/:session.json 记会话状态,drafts/ 存草稿与崩溃恢复快照。删除该目录即可完全重置应用(帮助菜单里有「打开数据目录」)。

中英双语界面跟随系统语言;目前已知边界:超大文件(>1MB)自动关闭语法高亮、暂无列编辑/书签/宏/插件系统(v2 候选)。

最后

随手记是最高频、也最不被认真对待的需求;轻量编辑是每个 Mac 用户的日常。NotepadMac 想做的就一件事:打开即写,永不丢失。开源项目,欢迎提 Issue、提 PR;觉得好用,点个 Star 就是最好的鼓励。
